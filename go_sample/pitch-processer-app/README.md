# PITCH File Volume Tracker

This is intended as a **demonstration project** drawing upon my experience with financial markets.

## Overview

PITCH files are generated by stock exchanges to disseminate trading events that occur on that exchange.

This project is a simplified fintech application that parses a PITCH file, processes trading events, and tracks the **total traded volume per symbol (financial instrument)**. At the end of processing, the application produces a **daily volume overview for all symbols encountered in the file**.

The project is intentionally simplified to focus on **event parsing and volume aggregation logic**.

---

## Assumptions

To keep the implementation simple, the following assumptions are made:

- **Single Currency**  
  All symbols trade in the same currency. No exchange rate conversion is required when calculating traded volume.

- **Volume Reporting**  
  The application outputs a summary of traded volume per symbol after the PITCH file has been fully processed.

- **Price Formatting**  
  All prices are represented to **two decimal places (2DP)**.

Example:

```
00001050 -> 10.50
```

---

## Architecture

The application is structured into three main packages.

### `pitchparser`

Responsible for parsing lines from the PITCH file.

Responsibilities:

- Identify the **event type** for each record.
- Extract required fields using **offset definitions**.
- Use a **JSON configuration file** to define:
  - Event identifiers
  - Field offsets
  - Field lengths

This design allows the parser to be adapted to **different exchange venues**, as PITCH file formats may vary between exchanges.

---

### `orderbook`

Handles parsed events and maintains the state required to track **traded volume per symbol**.

Responsibilities:

- Process events emitted by the parser
- Maintain symbol-level trade volume
- Update state as new events are received

---

### `main`

Coordinates application execution.

Responsibilities:

1. Create a `pitchparser` using the **JSON configuration file** provided as a command-line argument.
2. Create an `orderbook` instance.
3. Open the **PITCH file** provided as a command-line argument.
4. Parse each line of the PITCH file.
5. Feed parsed events into the order book.
6. After the file has been fully processed, output the **symbol volume summary**.

---

## Usage

Example command:

```bash
./pitch-volume-tracker <pitch_file> <parser_config.json>
```

Example:

```bash
./pitch-volume-tracker data/pitch.txt config/pitch_offsets.json
```

---

## Output

After processing the file, the application prints a **volume summary per symbol**.

Example output:

```
AAPL  125000
MSFT  98000
TSLA  45200
```
